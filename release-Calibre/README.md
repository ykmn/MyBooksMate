# Яндекс.Книги — плагин-магазин для Calibre

Добавляет в диалог "Купить книги" (Get Books) Calibre магазин **"Яндекс.Книги"**:
поиск книг на books.yandex.ru, авторизация в Bookmate (тот же аккаунт, что и в
desktop-приложении My Books Mate) и скачивание найденной книги прямо в текущую
библиотеку Calibre.

## Ограничения текущей версии

Поддерживаются только текстовые книги (`/books/<id>` → EPUB). Аудиокниги,
комиксы, сериалы и серии используют другие API-эндпоинты и пока не
реализованы в этом плагине (десктопное приложение `mybooksmate` их
поддерживает — см. корень репозитория).

Плагин не использует никаких сторонних библиотек (`httpx`, `bs4` и т.д.) —
только то, что уже есть в самом Calibre (`urllib`, `json`, Qt-обёртка
`qt.core`/`qt.webengine`), чтобы не вкладывать зависимости в zip.

Поиск идёт через собственный GraphQL-эндпоинт сайта
(`POST https://books.yandex.ru/node-api/p-graphql/`, см. `api.py`), а не
через скрейпинг HTML-страницы поиска — страница рендерит результаты на
клиенте (Next.js), поэтому в статическом HTML нет ничего, кроме случайных
"рекомендованных" книг. Сервер проверяет текст GraphQL-запроса по
allow-list, поэтому `SEARCH_QUERY` в `api.py` должен оставаться
побайтово идентичным запросу из реального браузера — не переформатируйте
его.

## Установка

1. Собрать zip-архив плагина (из корня `release-Calibre/`, все `.py`-файлы
   и маркер должны лежать прямо в корне zip — Calibre превращает корень
   архива в содержимое пакета `calibre_plugins.yandex_books`):
   ```
   cd release-Calibre
   zip -r ../YandexBooks.zip . -x "*__pycache__*" -x "*.pyc"
   ```
   Либо через сам Calibre (надёжнее, проверяет валидность):
   ```
   calibre-customize -b release-Calibre
   ```
   (тут `-b` сразу собирает и устанавливает плагин в Calibre на этой машине,
   без отдельного шага "Load plugin from file").
2. Если собирали zip вручную — в Calibre: **Preferences → Plugins → Load
   plugin from file** → выбрать `YandexBooks.zip` → перезапустить Calibre.
3. Открыть **Get Books** (значок "Купить книги") — в списке магазинов
   появится **Яндекс.Книги**. Ввести запрос для поиска.

   Сколько результатов вернёт магазин, ограничивается настройкой самого
   Calibre, а не плагином: **Настройки → Максимум результатов показа для
   каждого магазина** (шестерёнка/"Настроить" внизу диалога "Get Books").
   По умолчанию там обычно стоит небольшое число — при необходимости
   увеличьте его, иначе даже с учётом пагинации в `api.py` будет
   показано меньше книг, чем найдено.
4. При первом скачивании откроется окно авторизации Яндекс (OAuth) —
   нужно один раз войти в аккаунт с активной подпиской Bookmate; токен
   сохраняется в настройках Calibre (`plugins/yandex_books.json`) и
   повторно не запрашивается.
5. Выйти из аккаунта можно в **Preferences → Plugins → Яндекс.Книги →
   Customize plugin → Выйти из аккаунта Bookmate**.
6. Не забудьте перезапустить Calibre после установки/обновления плагина.

## Структура

```
release-Calibre/
  __init__.py                          # дескриптор плагина StoreBase (без Qt-импортов на уровне модуля)
  plugin-import-name-yandex_books.txt  # маркер уникального имени пакета для импорта (calibre_plugins.yandex_books)
  api.py             # поиск/метаданные/скачивание — только stdlib (urllib)
  metadata.py        # восстановление обложки и встраивание тегов/издательства/года в EPUB — только stdlib (zipfile, ElementTree)
  auth.py            # окно OAuth-входа (qt.webengine)
  config.py          # хранение токена (JSONConfig) + виджет настроек/логаут
  store.py           # StorePlugin.search()/open() — реальная логика, грузится лениво через actual_plugin
  download_dialog.py # скачивание + обложка/метаданные + добавление файла в библиотеку
```

При скачивании из результатов поиска книга проходит ту же обработку, что и
в десктопном приложении: обложка восстанавливается, если в EPUB от
Bookmate она отсутствует или повреждена (`metadata.fix_epub_cover`), а
теги/издательство/год года издания подгружаются со страницы книги на
books.yandex.ru и встраиваются в метаданные EPUB (`metadata.fetch_page_metadata`
+ `embed_epub_metadata`) — эти данные нет в Bookmate API.

Все `.py`-файлы (кроме `__init__.py`) лежат прямо в корне, а не в подпапке:
Calibre отображает корень zip-архива плагина как содержимое пакета
`calibre_plugins.yandex_books` напрямую (имя берётся из
`plugin-import-name-*.txt`), поэтому `store.py` рядом с `__init__.py`
становится модулем `calibre_plugins.yandex_books.store`, на который
ссылается `actual_plugin`.

## Минимальная версия Calibre

5.0.0+ (используется унифицированный модуль `qt.core`/`qt.webengine`,
появившийся в этой версии).
