# Дизайн: крупные цветные кнопки навигации + «Копировать ссылку на страницу»

## Контекст

Панель навигации браузера в `mybooksmate/main_window.py` (`_build_browser_container()`)
сейчас состоит из четырёх мелких `QToolButton` с текстовыми символами (←, →, ⟲, ⌂)
без выраженного визуального стиля. Правый клик по встроенному браузеру (`QWebEngineView`)
показывает только стандартное контекстное меню Chromium.

## Требования

1. Кнопки навигации (Назад, Вперёд, Обновить, На главную) должны быть крупнее и иметь
   цветной фон с контрастными иконками.
2. В контекстное меню браузера нужно добавить пункт «Копировать ссылку на страницу».

## Дизайн

### 1. Кнопки навигации

- Символы остаются текстовыми (←, →, ⟲, ⌂), без новых SVG-ассетов — крупный шрифт
  вместо иконок.
- Единый акцентный цвет фона для всех четырёх кнопок (не разный цвет на кнопку).
- Каждая `QToolButton` получает через `setStyleSheet`:
  - увеличенный `font-size` и `min-width`/`min-height` (крупнее текущего мелкого размера);
  - `background-color` в акцентном цвете, `color` — контрастный (светлый) для текста;
  - `border-radius` для скруглённого вида кнопки;
  - отдельные правила для `:hover` и `:pressed` (более тёмный/светлый оттенок акцента),
    чтобы сохранить обратную связь при наведении/нажатии.
- Стиль можно вынести в один общий QSS-фрагмент (константу модуля) и применить ко
  всем четырём кнопкам в `_build_browser_container()`, чтобы не дублировать строки.
- Изменения затрагивают только `_build_browser_container()` в `main_window.py`.

### 2. «Копировать ссылку на страницу» в контекстном меню

- Стандартное контекстное меню Chromium (Назад, Обновить, Копировать, Просмотр кода
  и т.д.) остаётся без изменений — новый пункт добавляется в конец, отделённый
  разделителем.
- Реализация: обработчик `customContextMenuRequested` (или переопределение
  `contextMenuEvent`) на `self.browser`, который:
  1. получает стандартное меню через `self.browser.page().createStandardContextMenu()`
     (либо аналогичный штатный способ получить меню Chromium со всеми пунктами);
  2. добавляет `menu.addSeparator()` и `QAction("Копировать ссылку на страницу")`;
  3. по срабатыванию action копирует `self.browser.url().toString()` в
     `QApplication.clipboard()` (текущий URL страницы, а не ссылка под курсором);
  4. показывает меню через `menu.exec(event.globalPos())`.
- Реализуется как небольшой метод в `MainWindow` (или тонкий helper), новых файлов
  не требуется.

## Тестирование

- Ручная проверка в приложении: клики по всем четырём кнопкам работают как раньше
  (визуально проверить размер/цвет/контраст, hover/pressed отклик);
- Правый клик в браузере → в меню есть «Копировать ссылку на страницу» в конце
  списка, стандартные пункты меню Chromium присутствуют и работают как раньше;
  выбор пункта кладёт текущий URL в буфer обмена (проверить вставкой).
- Автоматических тестов для Qt UI в проекте нет — только ручная проверка через /run.
